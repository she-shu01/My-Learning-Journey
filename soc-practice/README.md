# SOC Practice Lab

This project contains beginner SOC analyst practice using Linux and log analysis.

## Activities Performed
- Log generation and monitoring
- Failed login detection
- Brute-force attack analysis
- Incident reporting
- Security event investigation

## Linux Commands Used
- grep
- cat
- sort
- uniq
- cut
- echo
- nano

## Files Included
- incident_report.txt
- final_summary.txt

## Objective
To build foundational SOC analyst and Linux investigation skills.
